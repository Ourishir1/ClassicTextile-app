# Classic Textile

Classic Textile is an online fabric store that offers a wide range of high-quality textiles. Built with Java and Spring, it showcases essential e-commerce features.

## Features
- User and Admin Management
- Shopping Cart and Order Management
- Fabric Details and Categories
- Secure Login and JWT Authentication

## Technologies Used
- **Backend**: Java, Spring Framework
- **Frontend**: TypeScript, React
- **Database**: MySQL
- **Other**: REST APIs, JWT
